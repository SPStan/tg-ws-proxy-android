# Требования Елисея к Android-форку TG WS Proxy

## Цель

Поддерживать Android-приложение для подключения Telegram к локальному MTProto-прокси. Ориентир по функциям прокси — последний стабильный релиз [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy/releases/latest). Основа приложения и образец поведения переключателя TLS — [amurcanov/tg-ws-proxy-android](https://github.com/amurcanov/tg-ws-proxy-android). Владелец нового репозитория — SPStan. Целевое устройство Елисея работает на Android 17, сборка `CP3A.261005.005`.

## Обязательное поведение

- Сохраняй доступные в Android-форке запуск и остановку прокси, фоновый сервис с уведомлением, настройки, диагностику и подключение Telegram по ссылке. По умолчанию прокси слушает `127.0.0.1:1443`.
- В настройках должен быть один переключатель «Выключить TLS для CF-прокси и CF-worker». При чистой установке TLS включён. Сохраняй выбор между запусками. При изменении настройки пересоздавай затронутые соединения либо явно предлагай перезапустить сервис.
- При включённом переключателе исходящий WebSocket к CF-прокси и к Cloudflare Worker должен действительно работать без TLS. При выключенном — через TLS. Проверяй оба маршрута по отдельности. Другие маршруты, локальный MTProto и входящий Fake TLS имеют свои настройки. Исключи автоматическое понижение WSS до WS при ошибке TLS.
- Объясни в интерфейсе, что в режиме WS сетевому посреднику видны заголовки WebSocket и что выбранный сервер должен принимать WS. Используй этот режим только для указанных CF-соединений.

## Разработка и приёмка

- Перед переносом изменений фиксируй теги и SHA исходников. Сверяй реализацию по коду и тестам Flowseal. Для функций интерфейса настольной ОС указывай Android-эквивалент либо причину, по которой функция относится только к настольной ОС.
- Переиспользуй Android-интерфейс и нативный движок форка. Сохраняй историю, GPLv3 Android-проекта, MIT-уведомления для кода Flowseal и сведения об авторах.
- Готовый результат для Елисея — устанавливаемый APK, инструкция по сборке и подключению Telegram и результаты проверок. Указывай отдельно проверки на эмуляторе и на физическом телефоне с номером сборки. При отсутствии телефона оставляй конкретные шаги ручной приёмки.
- Пиши Елисею по-русски. Для новой процедуры давай воспроизводимые команды и ожидаемый результат. Перед завершением сверяй работу с исходной задачей или issue.
